# Kits
_(Built-in program factory kits)_

Kits are like lego sets, we can create our own packages using the pre-built blocks

Kits aim to help the engineer work with the program, in the mental-model shape-based world, rather than syntax. We focus on the layers of a program, and build it like architecture.

- 🟦 Kits (modules/packages)
- 🟩 State Machine
- 🟨 Functions (fx blocks)
- 🟪 Grammar (the sentence engine rules)
- 🟥 HTML builder / UI builder

## Standard kits
These are kits included with the language... like Java packages

- **"Math"** ...massive kits for everything math related
- **"Euclid"** ...contains advanced geometric mathematics useful for visualizations like WebGL and Canvas
- [Logger]() ...a more useful console log utility
- [State]() ...utilities to create massive state machines with ease
