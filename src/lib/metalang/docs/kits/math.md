# .random(x, y)
From two values, a minimum (x) and a maximum (y) this returns a randomized value between these two points. Useful for randomizing positions of cards or randomly positioning images for example.

# .pi()
Returns $PI (3.14)$ the distance between the diameter and circumference of a circle.
