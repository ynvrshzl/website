### Aliases
Neurovision, Brainlens

### Introduction
A high-performance, modular, <u>epic</u> component visualizes an interactive network graph for our website. Powered by the [Canvas API]() for high-performance scaling to thousands of articles and nodes.  Visualizes articles and links as an interactive network graph.

### Inspirations
Inspired by Obsidian.md, Capacities.io, LogSeq and Roam Resarch.
