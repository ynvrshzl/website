# Graph.js
Description: Mathematics-driven, Graph Websystem Data Visualization component

Aliases: Neurovision, Brainlens

Description: A Data Visualization tool for visualizing articles and media, Websystem Component


### Introduction
A high-performance, modular, <u>epic</u> component visualizes an interactive network graph for our website. Powered by raw javascript canvas for high-performance scaling to thousands of articles and nodes. Inspired by obsidian.md Visualizes articles and links as an interactive network graph inspired by obsidian.md
