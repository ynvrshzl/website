# Logical Processing Unit (LPU)
The processor is a communication bridge and controller for [state-based graphics]() and [signal processing.]()

Important does render anything, instead it is the translation layer between the external world entities and the internal rendering calls. This is becuase the graph follows a strict functional programming approach to work with graphical data safely.
