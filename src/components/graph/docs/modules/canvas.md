# Canvas
Essentially, the [HTML Canvas API]() operates as a __Processor__ and __Bitmap__

Essentially, the Canvas is painting a static image, one-by-one, using mathematical operations to describe each draw.

We can imagine this as a Paint brush, and a Conveyor belt of Mathematical operations. The paint brush can only read the next operation

### Limitations of the Canvas API
By default, a graphics processor does not hold state, data or user interaction.
