## Debugging
Debugging a Network Graph of this scale, especially the Cartesian Axis system, is required, becuase of it's visual nature, the debugger provides the human engineer visual aid.

Technically speaking, the debugger unit should have the ability to enable/disable... without fundamentally changing the graph system itself. This is why the cleanest method of doing this, is to treat "debug" as it's own entity, and a "mode" for the network graph. 

There might be future-use cases where we want to work with both debug + real-data, coming soon!
