# API
_Documentation: How to use the NetworkGraph API_

### Abstract:
The network graph is designed to be a reuseable component with it's own internal state. This means we can do neat stuff like... 

- Attach the Graph to any part of the HTML Websystem interface. 
- Multiple network graphs, each with their own views and settings. Useful for visualizing different levels of connections and contexts.
- And even use the NetworkGraph's visual-engine to visualize any kind of relational data!
