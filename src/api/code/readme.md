# API:Code

The __"Code API"__ gives _any_ markdown article the ability to run live JavaScript inside a codeblock.

> 

# [FAQ]
## When should I use this API?
This is especially helpful for dynamic layouts where positions.

While article [Assets](../../../documentation/articles/assets) provides real javascript files to be loaded alongside articles, the code-api executes javascript inside the article.


## When not to use?
Becuase of the code-api's codeblock nature... mixing markdown with javascript can get hard to read for our Authors. As such, the [Assets](../../../documentation/articles/assets) System was introduced.
