# Essential Files and Directories
This is a map of the essential files and directories for web-sys.


### Directories
Directories (folders) containing specific areas of the web
- [database/](../database/) ...backend systems
- [src/](../src/) ...javscript source code powering the entire website
- [media/](../media/) ...images, music, audio and media content
- [articles/](../articles/)
- [documentation/](../documentation/)

### Files
Files with notable purposes

- [package.json](../package.json) ...contains developer scripts 
- [.htaccess](../.htaccess) => critical for correcting any URL issues. Essentially handles incorrect URLs so they can be intercepted by the front-end source code withuot crashing the system with a "GET" error. Which is a red flag for average visitors.
