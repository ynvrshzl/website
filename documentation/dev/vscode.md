# VS Code
Development process for web-sys in vs-code


## Main
Development for our websystem begins with the vscode main build task.

The main build task can be accessed by the vscode default keyboard shortcut `Ctrl Shift B` or via the ["package.json"](../../package.json) scripts...  or by running the console command in the integrated terminal... `"npm start"`
