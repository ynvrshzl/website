## Purpose of Database
Essentially the database serves massive amounts of relational data between articles. 

- Articles are like the cells of our websystem. 
- The database is like the logic weaving these cells together

## Applications and Use cases of the Database
The database operates like a **graph/network.** Each markdown article can be thought of as a node. 

This is used by the frontend system to visualize the database in many amazing ways and deliver graph relational content, which makes the articles come to life by becoming a system, rather than static documents.

The database essentially stores important article properties so the website can load quickly.
